# Plan de Interlinking (Enlaces Internos)
**Objetivo:** Conectar artículos temáticamente para mejorar SEO y retención de usuarios

---

## ESTRATEGIA

**Principio:** Cada artículo debe enlazar a:
- 2-3 artículos relacionados del mismo tema
- 1 página de servicio relevante
- Nunca más de 5 enlaces internos (se dispersa atención)

## IMPLEMENTACIÓN

**Método manual (recomendado para control de calidad):**

Para cada artículo, busca esta línea:
```html
</article>
```

Y añade ANTES:
```html
<section class="pp-prose" style="margin-top:40px">
  <h3>Relacionado</h3>
  <ul>
    <li><a href="/blog/articulo-relacionado-1">Título artículo 1</a></li>
    <li><a href="/blog/articulo-relacionado-2">Título artículo 2</a></li>
    <li><a href="/servicio">Página de servicio</a></li>
  </ul>
</section>
```

**Método automático (si usas script):**
- Buscar `</article>` en cada HTML
- Insertar bloque de enlaces según tema
